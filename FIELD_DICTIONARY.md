# Screaming Frog Audit Field Dictionary

This file explains the fields added by `scripts/geo_screamingfrog_audit.py`.

Most other columns in the Excel output come directly from Screaming Frog's `Internal:All` export for the final resolved page URL. Those columns keep Screaming Frog's original names and meanings.

## URL Resolution Fields

| Field | Meaning |
| --- | --- |
| `Input URL` | The original URL provided in `INPUT_URLS`. |
| `Resolved URL` | The final URL the script uses after following redirect/canonical resolution checks. Semantic and no-render crawls are run against this URL. |
| `Resolution Method` | How the final URL was selected. `input` means the crawled URL was indexable. `canonical` means the URL was canonicalised and the script followed `Canonical Link Element 1`. `redirect` means the URL was redirected and the script followed `Redirect URL`. |
| `Redirect Target` | The value found in Screaming Frog's `Redirect URL` field for the current resolution step, if present. |
| `Canonical Target` | The value found in Screaming Frog's `Canonical Link Element 1` field for the current resolution step, if present. |
| `Resolution Chain` | A readable trail of the page-only resolution crawls, for example `page A -> page B (canonical) | page B -> page C (redirect)`. Resolution stops when an indexable page is reached or after 3 page-only resolution crawls. |

## Page Metrics

| Field | Meaning |
| --- | --- |
| `Address` | The page URL from Screaming Frog's `Internal:All` export for the final resolved page. |
| `Missing Alt Image Count` | A custom field expected to come from the page-only Screaming Frog `Internal:All` export. The Python script no longer calculates this from the Images tab. |
| Other Screaming Frog columns | All other page-level fields from the final resolved page-only crawl's `Internal:All` row, such as title, meta description, status code, indexability, headings, word count, custom JavaScript metrics, and any other configured exports. |

## Semantic Similarity Fields From Screaming Frog

These fields come from the semantic similarity crawl and are copied only for the final `Resolved URL`.

| Field | Meaning |
| --- | --- |
| `Extract embeddings from page content` | The page-level embedding generated by Screaming Frog/OpenAI for the resolved page content. In the current export this may be a plain comma-separated numeric vector rather than JSON. |
| `Closest Semantically Similar Address` | Screaming Frog's closest semantically similar page address. |
| `Semantic Similarity Score` | Screaming Frog's semantic similarity score for the closest similar page. |
| `No. Semantically Similar` | Count of semantically similar pages reported by Screaming Frog. |
| `Semantic Relevance Score` | Screaming Frog's semantic relevance score. |

## Prompt Similarity Fields Added By Python

These fields compare the fixed prompt embedding for `what is the best mba degree in canada?` against the page and passage embeddings.

| Field | Meaning |
| --- | --- |
| `page_similarity` | Cosine similarity between the prompt embedding and `Extract embeddings from page content`. |
| `max_chunk_similarity` | Highest cosine similarity between the prompt embedding and any chunk embedding inside `Passage Embeddings 1`. |
| `avg_top_3_chunk_similarity` | Average cosine similarity of the top 3 most similar chunks. If fewer than 3 valid chunks exist, averages the available chunks. |
| `relevant_chunk_count` | Number of valid chunks with cosine similarity greater than or equal to the configured threshold. The default threshold is `0.75`. |
| `embedding_similarity_warning` | Non-fatal embedding issues, such as missing page embeddings, invalid chunks, malformed JSON, missing `Passage Embeddings 1`, or dimension mismatches for some fields. |
| `embedding_similarity_error` | Fatal scoring error for the row, if the scorer could not complete unexpectedly. |

## No-Render Comparison Field

| Field | Meaning |
| --- | --- |
| `Word Count - Rendering Off` | The `Word Count` value from the no-render crawl's `Internal:All` export for the final resolved page. This can be compared with the rendered word count from the page-only crawl. |

## Run Status Fields

| Field | Meaning |
| --- | --- |
| `Error` | Row-level crawl or processing failure. The script continues to the next input URL when this is populated. |
| `Warning` | Row-level non-fatal warning, especially from URL resolution, such as max resolution crawl depth being reached or missing redirect/canonical target fields. |

## Embedding Field Shapes

`Extract embeddings from page content` is parsed as either:

```text
-0.043426513671875,0.02569580078125,0.0174560546875,...
```

or as a JSON numeric array.

`Passage Embeddings 1` is parsed as JSON shaped like:

```json
{
  "success": true,
  "model": "text-embedding-3-small",
  "chunks": [
    {
      "text": "Chunk text...",
      "index": 0,
      "metadata": {
        "elementType": "p",
        "xpath": "/html/body/...",
        "textLength": 123
      },
      "embedding": [0.01, -0.02, 0.03],
      "embeddingModel": "text-embedding-3-small"
    }
  ]
}
```
